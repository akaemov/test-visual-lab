# Visual Lab

Интерактивный статический прототип операционного дашборда без backend и базы данных. Все показатели — демонстрационные.

## Запуск

Откройте `index.html` в браузере или выполните:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Включено

- Адаптивная вёрстка
- Светлая и тёмная темы
- Фильтр карточек
- Демонстрационный диалог добавления
